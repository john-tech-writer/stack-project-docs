# README for reel and rod logs

*updated 8.22.26*

This folder contains the reel and rod logs for the Vintage Reel Service Guides project.

These logs include relevant information about the purchase, description, and condition of each item. Details on evaluation, service / parts / repairs, documentation, field use, and misc. notes are also included. The logs constitute a brief history of each reel as it moves through the workshop and project.

## Working approach

These files are updated whenever a new item is purchased as the first step in the workflow. Currently one file is in MS Word format and the others are in Markdown. Markdown (md) files are authored and edited in Notepad ++. This folder is included in backups to Dropbox.

These files are private records and are not included in the nav for the public repository. They are included in the project so that they are pushed to the repo on builds, so they can be viewed as built pages in GitHub.
