# Image lists

These lists are intended as flexible guidelines for typical projects.

## Repo

Overviews

  - Hero image
  - Vintage catalog image
  - Logo
  - Handles
  - Inside mechanism, e.g., inside of front plate
  - Controls / features with callouts, e.g., ABL - standards are in Affinity
  - Feature
  - Controls 2
  - Inside mechanism 2
  - Feature

Service guides

  - Test, e.g., checking the gears
  - Disassembly - step by step, some steps may have 2 - 3 images, as an example the Pflueger Nobby disassembly uses 26 images
  - Fully disassembled
  - Special maintenance features, e.g., grease disc
  - Resassembly - step by step, some steps may have 2 - 3 images, as an example the Pflueger Nobby disassembly uses 5 images - just highlights
  - Fully reassembled
  - Annotated controls, bench tests, 2 - 3 images
  - Vintage fish art
