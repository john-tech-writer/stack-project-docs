# Extra intro bits for stack-project-doc repo

It is intended to model a "gold standard" for technical documentation, supported by many years of practical experience, research, and deep integration with AI-assisted authoring.

This skeleton / model is suitable for a wide range of projects, from hardware-oriented maintenance and repair work to software-based workflows.

The documents include not only general guidelines and structure, but also prompts to help kick-start the process of authoring content. They also include more specific, concrete instructions for tool use, which is often a very time consuming aspect of new projects. For example, basic instructions are provided for using Shotcut to create and edit videos.
