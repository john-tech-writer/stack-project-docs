Setting screenshots folder

Application settings > Paths > check Use custom screenshots folder > Browse

Adding image effects

This example is for resizing a capture but the sequence can be used for any available effect.

Task Settings → Image / Effects → click Image effects configuration button → + / Preset → + / Effects → Manipulations → Resize / etc.

Set Width to your target, Height to 0 to keep proportions.

Back in the main window, enable After capture tasks → Add image effects so it actually fires on every capture or "show image effects window after capture" toggle to choose per-shot.

Screen recording

Capture > Screen recording > focus / click to select area in bounding box > records as mp4 / displays transport controls
